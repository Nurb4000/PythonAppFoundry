Dynamic Table Index Management

Manage indexes on dynamic tables created by modules. Indexes improve query performance for columns that are frequently filtered or sorted.

Best Practices:
  • Index columns used in WHERE clauses, JOIN conditions, or ORDER BY
  • Avoid indexing low-cardinality columns (e.g., boolean flags)
  • Each index adds overhead to INSERT/UPDATE operations
  • Monitor index usage to identify unused indexes
