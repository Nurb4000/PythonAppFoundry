Migration Process

  1. Create backup - A backup of your current database is saved automatically
  2. Export data - All tables and data are exported from the source database
  3. Import data - Data is imported into the new database with compatible schema
  4. Verify migration - Row counts are compared to ensure data integrity

Note: After successful migration, update your .env file with the new DATABASE_URL and restart the application.
